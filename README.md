## Layout

- `cadastre.json` — everything
- `by-region/{eu,us}.json` — one regime
- `by-section/*.json` — jurisdictions, rates, rules, classifications, sources
- `manifest.json` — version, hash, counts, file list

Every region and section file is filtered from the same compiled document, so
they cannot disagree with the combined one.

## Every fact cites its source

Each rate and rule carries the source it came from, the **hash of the exact
bytes** that were read, and when they were read. A URL says where we looked;
the hash says what was actually there, which is what keeps a claim checkable
after a publisher edits a page in place.

## Dates

A period's `until` is **inclusive**: a rate recorded as running until
`2024-09-30` applies ON that day. `until: null` means "still in force as far
as the source last said" — not "unknown".

## What this is not

A tax engine. It publishes what jurisdictions levy; deciding what a particular
supply owes — place of supply, liability, rounding — is a different problem and
lives elsewhere.

Rates are exact decimal **strings**. Parsing them into a binary float and back
is how `19.99` becomes `19.989999999999998`.
